Tab Triage

Every open Safari tab, sorted into folders. Check, close, undo.

This copy isn't signed

Safari only runs it after you allow unsigned extensions:

  1. Safari > Settings > Advanced: tick Show features for web developers (older Safari: Show Develop menu).
  2. In the menu bar: Develop > Allow Unsigned Extensions, then enter your password.

Safari turns this off every time it quits, so repeat it after each restart. Building Tab Triage from source with your own free Apple ID avoids this. How

  1. Turn on Tab Triage in Safari

    In Safari Settings > Extensions, tick Tab Triage.

    Checking…

  2. Allow it on every website

    Select Tab Triage in the list, click Edit Websites… and set When visiting other websites to Allow.

    Safari only shows an extension a tab's title and address on websites it's allowed on. Tab Triage reads nothing from the pages themselves.

  3. Private windows optional

    Tick Allow in Private Browsing to see private tabs too. Tab Triage never saves anything about private tabs.

  4. Find the button in Safari's toolbar

    Safari usually adds it. If it's missing: View > Customize Toolbar… and drag Tab Triage in.

All set. Click Tab Triage in Safari's toolbar. You can close this window.
